How It Works

From raw footage to
ranked brand inventory.

A modular, production-ready computer vision pipeline designed for video streaming platforms, OTT networks, and post-production studios.

01 / DISCOVERY

Open-Vocabulary Surface Detection

YOLOv8-World v2 zero-shot detection inspects incoming frames with dynamic lexical prompts to identify candidate planar surfaces: billboards, city bus sides, train interior panels, blank walls, and screens.

PROMPTS: 100+ LEXICAL CLASSES
02 / GEOMETRY

Quad Fitting & Tracklet Linking

Extracts precise four-point corners with sub-pixel contour approximation, calculates the 3x3 projective homography matrix, and links candidate planes across camera panning with Kalman-filtered tracklets.

HOMOGRAPHY: RANSAC 4-POINT
03 / EVALUATION

Multi-Factor Heuristic Ranking

Evaluates surface duration, area fraction, occlusion ratio, temporal stability, and aspect ratio normality to assign a composite score (0-100), allocating non-overlapping broadcast timeline slots.

OUTPUT: JSON, CSV & COMPOSITED MP4
Comprehensive System Architecture

Inside the Inscene Pipeline.

Explore the 6 modular processing stages that transform unstructured raw video pixels into measurable, ranked advertising slots.

STAGE 01 INGESTION

Video Decoding & Frame Extraction

Decodes MP4, WebM, MOV video containers via OpenCV. Normalizes resolutions up to 4K UHD, applies adaptive frame-striding (default 3x) to accelerate processing without missing transient ad spaces.

INPUT: Raw MP4 / MOV / JPG
OUTPUT: RGB Normalized Frame Buffer
STAGE 02 DETECTION

YOLOv8-World v2 Zero-Shot

Dual-branch detector evaluating two lexical prompt sets simultaneously: candidate planar surfaces (billboard, plain wall, train poster, screen) against dynamic foreground occluders (person, car, pole, tree).

MODEL: yolov8s-worldv2.pt
CONF / IOU: 0.10 / 0.45
STAGE 03 GEOMETRY

Sub-Pixel Quad & Homography

Fits 4-point quadrilaterals via convex hull contour approximation. Computes the 3x3 projective transformation matrix $H$ with RANSAC to calculate condition number, perspective tilt, and aspect distortion.

METHOD: cv2.findHomography (RANSAC)
METRIC: Frobenius Condition < 100
STAGE 04 TRACKING

Kalman Tracklet Association

Maintains spatial-temporal tracklets across frames with Hungarian matching and IoU overlap. Fuses cospatial tracklets when camera pans away and returns, preventing duplicate ad inventory fragmentation.

IOU MIN: 0.30 Overlap
GAP TOLERANCE: Max 6.0 sec re-identification
STAGE 05 SCORING

Multi-Factor Heuristic Scorer

Executes the paper's 5-pillar mathematical formulation: continuous screen-time duration, mean area fraction, foreground occlusion penalty, motion velocity stability, and geometric rectangle fidelity.

FORMULA: Weighted Linear Composite
RANGE: 0.0 to 100.0 Score
STAGE 06 EXPORT

Timeline Slotting & Export

Allocates non-overlapping broadcast timeline slots (e.g. 0:02 - 0:08s), identifies optimal placement candidates, and exports structured JSON, CSV spreadsheets, and H.264 browser-compatible annotated video.

ENCODER: FFmpeg H.264 (libx264)
INTEGRATION: FastAPI REST Endpoints
Core Tech Stack:
YOLOv8-World v2 OpenCV 4.10 PyTorch 2.4 FastAPI NumPy FFmpeg H.264
Hardware: CUDA GPU Accelerated / CPU Fallback

Frequently Asked Questions

Common Questions & Answers.

Inscene leverages YOLOv8-World v2, a vision-language foundation model. Instead of hardcoded class IDs, it accepts dynamic text token embeddings. By injecting structured lexical prompts (e.g. "billboard", "exterior city bus", "plain wall", "train carriage poster"), the model aligns visual features with semantic concepts zero-shot, enabling detection across hundreds of physical surface types out of the box.
The detector runs a concurrent lexical pass for occluding classes (pedestrians, vehicles, lamp posts, trees, columns). In each frame, Inscene computes the spatial polygon intersection between candidate ad quadrilaterals and foreground occluder masks. The intersection ratio ($P_{occl} \in [0.0, 1.0]$) directly subtracts up to 25 points from the composite placement score, penalizing surfaces obstructed by passing obstacles.
Given the four sub-pixel corner coordinates of the target planar quadrilateral and the rectangular aspect ratio of the brand advertisement graphic, Inscene computes the $3 \times 3$ projective homography matrix $H$ using RANSAC outlier rejection. This matrix maps every source pixel $(u, v)$ to target coordinates $(x', y')$ in projective space, seamlessly aligning pitch, yaw, roll, and vanishing lines.
Inscene includes a cospatial tracklet re-identification module. If an object leaves the frame for up to 6.0 seconds and reappears within matching centroid distance, aspect ratio, and class bounds, the tracker fuses the segments into a single unified physical tracklet, preventing duplicate or fragmented ad inventory allocations.
The system accepts MP4, WebM, MOV, AVI, MKV video files up to 4K resolution, as well as static photography (JPG, PNG, WEBP). Output videos are transcoded using browser-compatible H.264 (yuv420p) with FastStart metadata flags for instantaneous web streaming.
